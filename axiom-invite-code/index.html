Axiom invite code: where the field is and what to type

Last checked: 2 November 2026

On Axiom's email sign-up form, the field is called Invite code (optional). Type join10 there, or open https://axiom.trade/@join10 first and it fills in by itself.

Finding the field

  1. Go to axiom.trade and press Sign up.
  2. Pick the email option. The form shows a box for your email address.
  3. Below it is Invite code (optional). That is the referral code field.

"Invite code", "referral code", "sign-up code" and "access code" all mean this one field. The referral link is the same code built into an address.

What to type

join10: lowercase letters j-o-i-n and the number 10, no spaces. If you opened the link in the last hour on the same browser, it is already there.

If you leave it empty

The field is optional, so the form lets you finish without it. The account then has no referral, and Axiom's terms say current or former users do not count as new users, so it cannot be fixed later. Opening a second account for a code is ruled out by section 14 of the terms (no self-referral, no multiple accounts).

Google or Phantom sign-up

Axiom's sign-up page offers email, Google or Phantom. These notes have only seen the invite field on the email form. If you use Google or Phantom, open the link first on the same device and finish within the hour.

Is a code from a stranger safe?

A code is just a word in a form; it gives nobody access to your account. Keep the usual rules: the address must be axiom.trade, never pay for a code, and never share your seed phrase. Axiom's support page says help comes only through private Discord tickets.
