Axiom sign-up checklist with a referral code

Last checked: 2 November 2026

Ten checks, in order. Tick them as you go. The steps follow Axiom's sign-up page; the referral steps follow the tests on the notes page.

Before you start

  1. Decide which device you will sign up on. The referral code is stored only in the browser that opens the link.
  2. Have paper ready for the seed phrase. Axiom shows it during sign-up so you can recover your wallets.
  3. Open https://axiom.trade/@join10 on that device. The address bar should read axiom.trade.

During sign-up

  1. Press Sign up within about 60 minutes of opening the link.
  2. Choose email, Google or Phantom. With email, check that Invite code (optional) shows join10; if it is empty, type it.
  3. Finish the form and write the seed phrase on paper. Do not photograph it or paste it anywhere.

Right after

  1. Add SOL: send it to the wallet address Axiom shows, or buy it inside Axiom.
  2. Open the trading settings. Axiom's Solana fees page explains the priority fee, slippage limit and MEV protection; it calls MEV protection essential against front-running.
  3. Make the first trade small and read the fee line before confirming.
  4. On Discord, ignore anyone who messages you first claiming to be support.
